====================================================
  StreamHub - Direct Movie Streamer
  Version 2.0 (4KHDHub + HubCloud + HDHub4u)
====================================================

KAISE CHALAYEIN:
----------------
1. run.bat par Double Click karein
2. Browser mein http://localhost:5050 automatically khulega
3. Koi bhi link paste karein aur "Resolve & Stream" click karein

SUPPORTED LINKS:
----------------
✓ https://hubcloud.ist/drive/...
✓ https://4khdhub.one/...
✓ https://new8.hdhub4u.cl/...
✓ Aur bhi bahut saari movie hosting sites

FEATURES:
---------
✓ Movie Search    — HDHub4u par seedha search
✓ Link Resolver   — CDN link automatically dhundta hai
✓ Browser Player  — MP4 seedha browser mein chalao
✓ Multi-Audio     — Hindi/Tamil/Telugu track select karo
✓ VLC Launch      — 1-click VLC mein open
✓ Copy URL        — Kisi bhi player mein paste karo

REQUIREMENTS:
-------------
• Python 3.8+  (https://www.python.org/downloads/)
  Install karte waqt "Add to PATH" tick karna na bhoolo!

OPTIONAL (for browser transcoding + VLC):
• FFmpeg  — https://ffmpeg.org/download.html
• VLC     — https://www.videolan.org/vlc/

PROBLEMS?
---------
• Python nahi mila  → Python install karein, PATH mein add karein
• VLC kaam nahi kar raha → VLC install karein ya URL copy karke manually open karein
• Link resolve nahi hua → Directly browser mein kholo, site ka structure change hua hoga
