====================================================
  StreamHub - Direct Movie Streamer
  Version 2.0 (4KHDHub + HubCloud + HDHub4u)
====================================================

HOW TO RUN:
-----------
1. Double-click run.bat
2. http://localhost:5050 will open automatically in your browser
3. Paste any supported link and click "Resolve & Stream"

SUPPORTED LINKS:
----------------
✓ https://hubcloud.ist/drive/...
✓ https://4khdhub.one/...
✓ https://new8.hdhub4u.cl/...
✓ Many more movie hosting sites

FEATURES:
---------
✓ Movie Search    — Direct search on HDHub4u
✓ Link Resolver   — Automatically extracts direct CDN streams
✓ Browser Player  — Stream MP4/HLS directly in your browser
✓ Multi-Audio     — Switch Hindi/English/Tamil/Telugu audio tracks
✓ VLC Launch      — 1-click playback in External VLC
✓ Copy URL        — Paste into any external media player

REQUIREMENTS:
-------------
• Python 3.8+  (https://www.python.org/downloads/)
  Be sure to check "Add Python to PATH" during installation!

OPTIONAL (for browser transcoding + VLC):
• FFmpeg  — https://ffmpeg.org/download.html
• VLC     — https://www.videolan.org/vlc/

TROUBLESHOOTING:
----------------
• Python not found      → Install Python and add it to your system PATH
• VLC not launching     → Install VLC or copy the stream URL and open it manually
• Link failed to resolve → Open in a browser directly; the site layout may have updated
